About Me

👋 Hi, I'm Miral Harsora, a Full Stack Web Developer specializing in React, Node.js, Express.js, and cloud-native application development. I completed the Full Stack Web Development program from AlmaBetter, in collaboration with IIT Guwahati.

I build secure, responsive, and scalable products across the frontend, backend, and cloud. My experience includes TypeScript, Vite, REST APIs, Python/FastAPI, MongoDB, Cloudflare, Google Cloud Run, Docker, GitHub Actions, automated testing, and CI/CD.

My flagship project is Imviora, a hybrid browser-and-cloud AI image-processing SaaS that I am actively building with secure authentication, billing, batch workflows, AI inference, and administration tools. It combines a modern full-stack and cloud-native architecture with GenAI-assisted engineering using ChatGPT and Claude Code for architecture reviews, development, debugging, automated testing, CI/CD configuration, and technical documentation. I validate the resulting work through code review, automated tests, and smoke checks. I personally configure the deployment stack—including Cloudflare Workers, Google Cloud Run, environment variables, secrets, service bindings, and release workflows—to deliver secure, environment-aware deployments.

Before moving into full-stack development, I gained more than 5 years of professional Android development experience, leading the end-to-end development and delivery of native mobile applications.
